# Radhika Sahani — Portfolio

Personal product portfolio. A single-page static site (HTML/CSS/JS, no build step).

## Run locally
Open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Files
- `index.html` — the site (all styles and scripts inline)
- `resume.pdf` — downloadable resume
- `headshot.jpg` — hero photo
